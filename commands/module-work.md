이 리포에서 코드를 고치는 작업 한 건을 계약 → 수정 → 게이트 → 리뷰 → 커밋 순서로 끝까지 몬다.

인자로 받은 것이 이번 작업의 요청이다: $ARGUMENTS

루프는 `npx --no-install almandu-module-loop` 다 (하네스 패키지의 bin 이고, 판본은 package.json 이 고정한 태그가 정한다).
**루프도 게이트도 이 리포에서 고치지 않는다** — `node_modules/` 안은 설치된 사본이라 고치면 다음 `npm i` 에 사라진다. 하네스는 하네스 리포에서 고치고 새 태그로 들어온다.
고칠 이유가 보이면 하네스 리포에 알린다.

## 1. 어디를 고칠지 먼저 말한다

고칠 파일 경로로 세션을 연다. 아직 아무것도 고치지 않는다.

```
npx --no-install almandu-module-loop scope <경로>...
```

루프가 내는 것은 **읽어야 할 계약 목록**이다. 그 MODULE.md 를 `cat` 이 아니라 **Read 로** 연다 — 같은 디렉토리의 CLAUDE.md 규칙이 함께 실려야 한다.
범위는 여기서 정해진다. 뒤에서 목록 밖 파일을 건드리면 5단계에서 커밋이 거부된다.

MODULE.md 가 한 장도 없으면 목록이 빈다 — 먼저 `/module-draft <디렉토리>` 로 계약서를 하나 세운다.

## 2. 계약을 읽고, 그다음 고친다

고치는 것은 이 세션이다. 루프는 고치는 도구가 아니라 고치기 전에 계약을 펴 놓게 하는 장치다.

- 불변식을 깨는 변경이면 **MODULE.md 를 먼저 고치고** 이력에 한 줄 남긴다
- 줄바꿈을 통째로 바꾸지 않는다 — CRLF 파일을 LF 로 바꾸면 게이트의 R11 이 눈을 감는다
- 범위 밖 파일이 필요해지면 고치기 전에 `scope` 를 다시 부른다

## 3. 기계에게 먼저 검사받는다

```
npx --no-install almandu-module-loop reconcile
```

게이트가 규칙 위반을 세고, 루프가 "이번 변경이 어느 계약을 약하게 했나" 를 되묻는다.
**FAIL 이면 4단계로 가지 않는다** — 기계가 이미 거부한 것에 사람 판단을 붙일 이유가 없다. 여기서 고치고 다시 돌린다.

## 4. 불변식 판정자에게 묻는다

`/module-review` 를 실행한다. 그 커맨드가 절차를 갖고 있으므로 여기서 다시 적지 않는다. 두 가지만 지킨다:

- 서브에이전트에 **이 대화 맥락을 넘기지 않는다.** 자기 변경을 자기가 리뷰하면 판정이 아니라 변명이 된다
- 통과가 아닌 답의 reason·evidence 는 5단계 `commit` 이 `Review-Verdict:` 트레일러로 커밋에 싣는다 — 따로 보존하지 않는다

`거짓` 이 나오면 그 전문을 사용자에게 그대로 보여주고 **사고인지 오탐인지 묻는다**. 판단은 사람이 한다.
검출은 늦게 온다 — 통과만 이어지는 회차는 아무것도 알려 주지 않는다.

## 5. 답을 커밋에 박아 넣는다

```
npx --no-install almandu-module-loop commit -m "<type>(<scope>): <제목>" [--contract "<계약 칸을 왜 고쳤나 한 줄>"]
```

- 계약 칸을 고쳤으면 `--contract` 없이는 커밋되지 않는다 (루프 I6)
- `--dry-run` 으로 `Review:` 트레일러를 먼저 확인할 수 있다
- 리뷰 결과는 커밋을 막지 않는다. 막는 것은 게이트의 종료 코드뿐이다
- 커밋은 사용자가 요청했을 때만 한다. 요청이 없으면 4단계까지 하고 멈춰 보고한다

## 하지 말 것

- 1단계를 건너뛰고 바로 고치기 — 범위 밖 파일은 5단계에서 거부되고, 그때 되돌리는 것이 더 비싸다
- 고친 세션이 자기 변경을 리뷰하기
- 리뷰 결과로 커밋 막기 — 막고 싶은 것이 생기면 그건 게이트 규칙 후보다
- `npx --no-install almandu-harness-init` 을 기본값으로 돌리기 — 설치 스크립트가 이미 훅을 연결했고, 기본값으로 다시 돌리면 이 리포의 `core.hooksPath` 를 덮을 수 있다. 돌릴 일이 생기면 지금 값을 `--hooks-path` 로 넘긴다
